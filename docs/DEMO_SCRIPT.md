5. אכיפה ← התיק ← הגשת ערעור ← קבלת הערעור. הסנקציה מוסרת והבדיקה במעבר חוזרת לרגיל.
6. **(אופציונלי) אותה הלבנה ב-NiFi, כפי שנדרש בקול הקורא:** מעלים לפני הדמו, כי זה דורש כ-1.5GB נוספים:
   `docker compose --profile core --profile nifi up -d nifi`.
   - פותחים https://localhost:8443/nifi (`ipp-admin` / `ChangeMe-Dev-Only-12`), ונכנסים לקבוצה **IPP ingest (whitening)**. ההוראות לייבוא הראשון נמצאות ב-[NIFI.md](NIFI.md).

## שאלות צפויות: תשובות קצרות
- **למה outbox?** כדי שלא תהיה כתיבה כפולה (dual write). האירוע נכתב באותה טרנזקציה כמו הנתון.
- **מה קורה אם Redis נופל?** ה-cache הוא אופטימיזציה ולא תלות. נופלים ל-read-model ב-Postgres.
- **איך מגדילים?** השירותים stateless, ו-`--scale` עובד. בפרודקשן, Kubernetes Service במקום DNS round-robin (G-32).
- **רשת סגורה?** `scripts/offline/bundle.sh` ו-`load.sh`, הכול מוצמד, אין CDN. ראו `docs/CLOSED_NETWORK.md`.
