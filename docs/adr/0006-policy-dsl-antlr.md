# ADR 0006 – DSL לחוקות עם ANTLR4 ומפרש AST
**סטטוס:** מאושר · 20/11/2026 · מימוש: policy-service (סוכן הענן, branch `cloud/policy-and-mock`)

## הקשר
מנהלי מדיניות צריכים לשנות תנאי זכאות בלי deploy, עם הסבר לכל החלטה.

## חלופות
- **SpEL, JavaScript או Groovy:** חזקים, אבל מריצים קוד שרירותי, ולכן פותחים פתח להזרקת קוד. נפסלו.
- **Drools:** כבד, עם עקומת למידה גבוהה.
- **JSON rules:** בטוח, אבל לא קריא למשתמש עסקי.
- **DSL עם ANTLR4, AST ב-JSON ומפרש ב-Java טהור** (נבחר).

## החלטה
הטקסט עובר parse ל-AST, שנשמר ב-Mongo יחד עם הטקסט וה-hash שלו. המפרש תומך רק באופרטורים ובפונקציות מ-whitelist (`quota()`, `sanctions.activeFor()`), ומחזיר עץ נימוקים. לכל חוקה יש גרסה, תאריך תחילה וסטטוס (טיוטה או פעיל).

## השלכות
אין דרך להריץ קוד מתוך חוקה. מוסיפים פונקציה חדשה ב-DSL על ידי שינוי קוד ו-review.
