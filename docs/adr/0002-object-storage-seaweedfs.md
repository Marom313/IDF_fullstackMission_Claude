# ADR 0002 – אחסון אובייקטים: SeaweedFS
**סטטוס:** מאושר · 20/11/2026

## הקשר
צריך אחסון תואם S3 לתמונות, למסמכים ול-PDF, שרץ offline.

## חלופות
- **MinIO:** מאגר ה-Community הועבר לארכיון ב-2026 ואינו מתוחזק. נפסל.
- **Ceph RGW:** כבד מדי למחשב פיתוח.
- **Garage:** מתאים, אבל קהילה קטנה יותר.
- **SeaweedFS** (Apache 2.0) עם S3 API מובנה. נבחר.

## החלטה
SeaweedFS במצב `server -s3` עם קונטיינר יחיד ו-256MB. הקוד משתמש ב-AWS SDK v2 מול endpoint כללי, עם `pathStyleAccessEnabled=true`.

## השלכות
מעבר לאחסון ארגוני תואם S3 הוא שינוי הגדרה בלבד (endpoint, מפתחות). ראו G-05 ב-GAPS.
